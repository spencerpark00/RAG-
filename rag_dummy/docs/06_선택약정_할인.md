# 선택약정 요금할인 안내
- 문서번호: DISC-001 / 시행일: 2025-01-01

## 개요
- 단말 지원금 대신 매월 요금의 25%를 할인받는 제도입니다.
- 약정 기간은 12개월 또는 24개월 중 선택합니다.

## 할인액 계산
- 월 할인액 = 월정액 × 25%
- 예) 5G 스탠다드(69,000원) → 월 17,250원 할인

## 유의사항
- 약정 기간 중 해지하면 할인반환금(위약금)이 발생합니다. 현행 기준은 'DISC-002 할인반환금 규정'을 따릅니다.
- 요금제 변경 시 변경 후 요금제 기준으로 할인액이 다시 계산됩니다.
