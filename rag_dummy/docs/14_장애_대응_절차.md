# 네트워크 장애 대응 절차
- 문서번호: OPS-001

## 장애 등급
| 등급 | 정의 |
|---|---|
| P1 | 전국 또는 광역 단위 음성·데이터 전면 불능 |
| P2 | 특정 지역 또는 일부 서비스 장애 |
| P3 | 개별 고객 또는 소수 기지국 영향 |

## 등급별 대응 기한 (장애 인지 시점 기준)
| 등급 | 상황 전파 | 임원 보고 | 고객 공지 |
|---|---|---|---|
| P1 | 10분 이내 | 30분 이내 | 60분 이내 (문자+홈페이지) |
| P2 | 30분 이내 | 2시간 이내 | 4시간 이내 (홈페이지) |
| P3 | 당일 | 해당 없음 | 개별 안내 |
